# Content contract v1
Release: releases/<version>/content.sqlite; releases/current.json contains version,path(relative directory),manifest_sha256. Read only SQLite URI mode=ro; never attach userdata here.
Tables questions/materials/cards/concepts/occurrences/papers/annotations/assessments/assets/id_aliases: id TEXT PRIMARY KEY,data TEXT NOT NULL (complete entity JSON). questions additional columns question_id,revision,module,status,practice_ready,material_id,stem. `status` = answer_status. Indexes module/status/practice_ready. No answers in student API projection.
Question: question_id q-<sourceqid>, revision 1, stem_markdown,stem_html, options[{option_id:q-<qid>-opt-A,label,text,html}], source_answer:{option_ids:[],status:source_only}, verified_answer:null|{option_ids:[],evidence_refs:[]}, answer_status:source_only|verified|disputed|unresolved, material_id:null|string, candidate_material_ids:[], material_binding_status:unknown|source_inferred|verified|rejected, classification_status,concept_ids,normalized_module,source_refs,practice_ready bool,practice_blockers[].
Verified material null means independently checked question; unknown null does NOT mean independent. Only practice_ready true can be served; default answer_status verified; source_only explicit opt in. Backend source-only scoring must remain separate.
Overlay directory optional contains questions/materials/cards/annotations/assessments.jsonl. Question patches merge by question_id; no automatic verification. To mark practice_ready require material_binding_status verified and answer integrity; verified_answer must carry evidence_refs. For human assessment reviewer_type human must not be synthesized.
Assets stored assets/<sha256>.<ext> with asset IDs a-<sha256>; HTML img src uses that relative path. All assets preserve source paths and provenance; analysis-only images not required to practice.
Use pipeline.store.resolve_current(releases_root) -> Path; load_entity(conn,table,id)->dict|None. Release manifest hash validation and atomic current replacement only after build validation. Source answer/analysis only available in backend full entity, not student rendering.
