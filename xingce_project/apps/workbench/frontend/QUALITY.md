本次源码提交重新执行了 TypeScript 检查、16 项 Node 测试和生产构建；具体记录见 [VALIDATION.md](../../../VALIDATION.md)。本次未重新执行浏览器端到端检查。

## 已知限制

- 星标、当前小题索引属于浏览器辅助状态，不包含在 SQLite 备份内。
- 双击、刷新、失败网络与真实视觉行为需要另做浏览器验收；后端接口仍是最终数据和答案隔离边界。
- 图片映射、方法卡状态和可练准入以内容流水线为准，不由前端认证。
- 离线运行需提前准备 Python 依赖、可信内容 release 和构建后的 dist。
